# UI components

## Three tiers

| Tier                   | Folder                                                        | What belongs there                                                               |
| ---------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Primitives (shadcn/ui) | `src/shared/ui/`                                              | Button, Dialog, Select, Sidebar… generated by the CLI                            |
| Generic compositions   | `src/shared/components/`                                      | `PageHeader`, `Pager`, `ConfirmDialog`, `PageLoader`, `Kbd`                      |
| App-aware components   | `src/core/**/components`, `src/core/layout`, `src/core/forms` | `Page`, `Head`, `TextField`, `ModeToggle`, `ThemeCustomizer`, `LanguageSwitcher` |
| Feature components     | `src/features/<name>/components/`                             | Anything used by one feature only                                                |

Rule of thumb: start inside the feature. Move a component down **only when a second feature
needs it**: to `shared/components` if it is generic, to `core` if it knows about the app
(translations, routes, session).

## shadcn/ui

The components are source files you own. They are configured by `components.json` (style
`radix-nova`, aliases pointing to `@/shared/ui`, `@/shared/lib/cn`, `@/shared/hooks`).

```bash
npx shadcn@latest add calendar           # add a component
npx shadcn@latest add button --overwrite # update one from upstream
```

`src/shared/ui` is excluded from ESLint and Prettier so upstream updates diff cleanly. Keep edits
there minimal. The one local change is `sonner.tsx`, which takes the theme as a prop instead of
using `next-themes`.

## Shared components

```tsx
<Page title="Tasks" description="…" actions={<Button>New</Button>} width="wide">…</Page>

<ConfirmDialog
  trigger={<Button variant="ghost">Delete</Button>}
  title="Delete task?"
  description="This can't be undone."
  confirmLabel="Delete"
  cancelLabel="Cancel"
  destructive
  pending={mutation.isPending}
  onConfirm={() => mutation.mutateAsync(id)} // stays open until it resolves
/>

<Pager page={2} totalPages={5} onPageChange={setPage} labels={{ previous, next, status }} />
```

## Icons

[lucide-react](https://lucide.dev). Import icons individually (`import { Plus } from 'lucide-react'`)
so unused ones are tree-shaken.

## Accessibility checklist

- Every icon-only button has an `aria-label`.
- Inputs are linked to labels (`TextField` does this). Errors set `aria-invalid`.
- Dialogs have a `DialogTitle` (add `className="sr-only"` if it shouldn't be visible).
- Tests query by role and accessible name. If you can't find an element that way, it probably
  has an accessibility problem.
